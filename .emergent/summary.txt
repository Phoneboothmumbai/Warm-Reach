<analysis>**original_problem_statement:**
The user wants to build a context-aware, controlled outreach SaaS called Warm Outreach Engine to help B2B service companies create demand via Email and WhatsApp.

**PRODUCT REQUIREMENTS:**
1.  **AI Content Generation:** The app must use the user's specific business context to generate relevant messages. All hardcoded content must be removed, and generation should rely solely on a per-tenant Business Profile.
2.  **Core Automation Loop (Set & Forget):**
    *   Auto-generate and send messages to **10 random contacts via WhatsApp** and **10 random contacts via Email** per day.
    *   Messages must be sent only during **business hours (9 AM - 6 PM)**.
    *   A contact should receive a **maximum of 2 messages per month**.
    *   The system should run daily without manual intervention.
3.  **Customizable AI Parameters:** The user must be able to define their own master lists for Intents, Angles, and CTAs from a settings page. The AI blueprint generator should include options for message length (Short, Medium, Long) and CTA selection.
4.  **Approval Workflow:** A semi-automatic flow is required where the user approves generated messages once, after which they are added to the automated daily sending queue.
5.  **Super Admin Portal:** A comprehensive backend portal is required for managing the SaaS, including a dashboard, management of tenants/users/subscriptions, a dynamic pricing plan manager, and a simple CMS.
6.  **SaaS Landing Page:** A public-facing marketing page.
