**SYSTEMATIC BUILD INSTRUCTIONS**

**Project:** Warm Outreach Engine (SaaS)

**CORE OBJECTIVE:**
Build a SaaS that helps B2B service companies proactively create demand via Email, WhatsApp, and LinkedIn, without spamming. The system should act like a disciplined junior sales assistant.

**PHASE-WISE BUILD PLAN:**

*   **PHASE 0: FOUNDATION & TENANCY:** Secure, multi-tenant architecture with user roles (Owner, Admin, Sales User, Read-only) and email/password authentication.
*   **PHASE 1: CONTACT & DATA CORE:** A contact database with fields like name, email, company, status, and critical context flags (, , etc.) to block outreach. Features include CSV import, deduplication, and manual editing.
*   **PHASE 2: TEMPLATE & BLUEPRINT ENGINE:** Create reusable message blueprints (structure + intent) with metadata like channel, intent, angle, tone, and cooldown period.
*   **PHASE 3: AI MESSAGE GENERATION:** Use AI (OpenAI GPT-5.2) to generate fresh, human-feeling content based on blueprints, with strict constraints (e.g., no inventing facts) and channel-specific rules. The system must have memory to avoid repetition.
*   **PHASE 4: SCHEDULER & RATE LIMITER:** Enforce global channel limits (e.g., 10 emails/day per tenant) and human-like sending schedules (business hours, randomized times).
*   **PHASE 5: APPROVAL & MODES:** Default to a manual approval mode where a user must approve all generated content.
*   **PHASE 6: CHANNEL INTEGRATIONS:** Use official APIs for Email (AWS SES), WhatsApp (Business Cloud API), and LinkedIn (Company Page automation only).
*   **PHASE 7: REPLY & SENTIMENT HANDLING:** Capture replies and classify sentiment to trigger rules (e.g., negative sentiment -> blacklist).
*   **PHASE 8: ANALYTICS THAT MATTER:** Track meaningful metrics like reply rate, positive sentiment rate, and meetings booked.
*   **PHASE 9: SAAS HARDENING:** Add tenant dashboards, abuse detection, and audit logs.

**MVP SCOPE:** Phases 0-5.
